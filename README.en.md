# Premiere Marker Review Export

Exports Premiere sequence markers as a local review report with stills, video previews, and comments.

## Choose a version

| Version | Premiere | Platform | Directory |
| --- | --- | --- | --- |
| 2026 | Premiere 26.3+ | UXP | [`uxp-2026/`](uxp-2026/) |
| 2022 | Premiere Pro 22.x | CEP | [`cep-2022/`](cep-2022/) |

Use the 2026 UXP version for new installations. The 2022 CEP version remains available for its original host.

## Development

```sh
npm install
npm test
npm run build
```

See [`uxp-2026/README.en.md`](uxp-2026/README.en.md) for UXP loading, packaging, and Windows validation.
